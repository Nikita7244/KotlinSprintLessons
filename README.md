# Kotlin-онбординг: шаблон учебного проекта

Шаблон проекта для спринта «Kotlin-онбординг: 25 задач» школы AI Sprints.
Из него вы создаёте свой репозиторий `KotlinSprintLessons` и дальше сдаёте
в нём задачи через pull request.

## Как начать

1. Нажмите **Use this template → Create a new repository**. Владелец — ваш
   аккаунт, имя — `KotlinSprintLessons`, видимость — **Public**.
2. В IDE на приветственном экране: **Clone Repository**, вставьте адрес своего нового репозитория.
3. Дождитесь, пока IDE загрузит Gradle, и откройте
   `src/main/kotlin/Main.kt`.
4. Запустите `fun main` зелёным треугольником слева от неё. В консоли
   появится `Hello, Kotlin!` — проект работает.

## Структура

```
src/main/kotlin/Main.kt    — точка входа, с неё начинается первый запуск
build.gradle.kts           — сборка: Kotlin на JVM
settings.gradle.kts        — имя проекта
.github/workflows/build.yml — проверка, что проект собирается
```

Каждая задача курса — отдельный файл `.kt` рядом с `Main.kt`, со своей
`fun main()`.

## Как сдавать

- На каждую задачу — своя ветка от `main`, имя ветки называет задача.
- Закоммитьте файл задачи, запушьте ветку и откройте pull request в `main`
  своего репозитория. Ссылку на PR отправьте в задаче на платформе.
- Замечания ревью правятся новым коммитом в ту же ветку. PR остаётся
  открытым до зачёта.
- Вопросы по задаче — ИИ-ментору в задаче на платформе или ментору-человеку.

Проверка `build` на pull request показывает только одно: проект
компилируется. Задачу принимает ревью на платформе.

## Требования

- JDK 21 или 25 (LTS) — IDE скачает его сама.
- IDE: OpenIDE Community или IntelliJ IDEA.
- Git и аккаунт на GitHub.
